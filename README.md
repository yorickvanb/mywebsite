# Yorick van Boheemen | Improv Comedian

A small one-page, Linktree-style landing page built with HTML and htmx for an improv comedian brand.

## About

This project is a compact, theatre-inspired personal landing page designed to feel warm, playful, and welcoming. It is optimized for mobile and desktop, with a single-screen layout and easy access to show dates, social links, and booking information.

## Run locally

From the project folder:
  
```bash
py -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```
